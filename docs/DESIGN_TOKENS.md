# Spetser AI — Design Tokens Reference

Reference documentation linking `docs/DESIGN_TOKENS.json` and `frontend/src/index.css`.

## Core Palette (Perplexity AI benchmark - 16/17 parity)
- **Brand / Accent**: `#01696D` (Teal)
- **Brand Hover**: `#017a7f`
- **Brand Light**: `#E6F4F4`
- **Background (Light Mode)**: `#F9F8F4` (Cream canvas)
- **Background (Dark Mode)**: `#0F0E17`
- **Surface**: `#FFFFFF` (Light) / `#1A1923` (Dark)
- **Text Primary**: `#1A1A1A` (Light) / `#F9F8F4` (Dark)
- **Text Secondary**: `#6B7280` / `#A09FA8`
- **Border**: `#E5E7EB` / `#2D2C3A`
- **Border Focus**: `#01696D`

## Typography
- Primary Sans: `Inter, -apple-system, BlinkMacSystemFont, sans-serif`
- Code / Monospace: `JetBrains Mono, monospace`

## Spacing & Elevation
- Baseline: 4px grid (`4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px`, `64px`)
- Card Radius: `12px` (Medium), `16px` (Large)
- Micro-interactions: 200–300ms transitions (`cubic-bezier(0.4, 0, 0.2, 1)`)
